🎵 Trích xuất lời bài hát

Link YouTube hoặc video có sẵn trong máy → lấy lời → cho AI đọc và phân tích.

Hỗ trợ link dạng youtube.com/watch?v=..., youtu.be/..., youtube.com/shorts/...

Cách lấy đường dẫn nhanh: trong Windows Explorer, giữ Shift + bấm chuột phải vào file → chọn Copy as path → dán vào ô trên. Cách này tool đọc thẳng file gốc, nhanh hơn và không tốn thêm dung lượng. Còn nút "Chọn file từ máy" sẽ sao chép tạm file lên tool rồi tự xoá sau khi nghe xong.

Nhận cả video (mp4, mkv, webm, mov…) và file tiếng (mp3, m4a, wav…). Nếu chọn sẵn file phụ đề (.srt, .vtt, .txt) thì tool đọc luôn, không cần nghe.
